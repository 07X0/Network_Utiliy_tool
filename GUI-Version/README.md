Network Utility Tool - GUI Version

Overview

The GUI version of Network Utility Tool provides a graphical interface built with Python and Tkinter.

It allows users to access network utility functions through buttons and a graphical output console instead of entering commands manually.

Features

- Graphical User Interface built with Tkinter
- DNS Lookup
- Reverse DNS Lookup
- TCP Service Name Lookup
- TCP Port-to-Service Lookup
- TCP Port Scanning
- Local Network Information
- Network Host Scanning
- Clear Console Output

Technologies

- Python 3
- Tkinter
- Socket Programming
- ThreadPoolExecutor

Requirements

- Python 3
- Tkinter

Install Tkinter separately on Linux if it is not already available.

For Debian and Ubuntu:

sudo apt install python3-tk

Run

From the root project directory:

python GUI-Version/network_utility_gui.py

Or navigate to this directory and run:

python network_utility_gui.py
