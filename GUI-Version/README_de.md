Network Utility Tool – GUI-Version

Überblick

Die GUI-Version des Network Utility Tools bietet eine grafische Benutzeroberfläche, die mit Python und Tkinter erstellt wurde.

Sie ermöglicht es Benutzern, Netzwerk-Dienstprogramme über Schaltflächen und eine grafische Ausgabekonsole zu nutzen, anstatt Befehle manuell eingeben zu müssen.

Funktionen

- Grafische Benutzeroberfläche (erstellt mit Tkinter)
- DNS-Abfrage (DNS Lookup)
- Reverse-DNS-Abfrage
- Abfrage von TCP-Dienstnamen
- Zuordnung von TCP-Ports zu Diensten
- TCP-Port-Scan
- Informationen zum lokalen Netzwerk
- Scan nach Netzwerk-Hosts
- Konsolenausgabe löschen

Technologien

- Python 3
- Tkinter
- Socket-Programmierung
- ThreadPoolExecutor

Voraussetzungen

- Python 3
- Tkinter

Unter Linux muss Tkinter gegebenenfalls separat installiert werden, falls es noch nicht vorhanden ist.

Für Debian und Ubuntu:

sudo apt install python3-tk

Ausführung

Vom Hauptverzeichnis des Projekts aus:

python GUI-Version/network_utility_gui.py

Oder navigieren Sie in das entsprechende Verzeichnis und führen Sie folgenden Befehl aus:

python network_utility_gui.py
