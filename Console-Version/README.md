Network Utility Tool - CLI Version

Overview

The CLI version of Network Utility Tool is a Python-based command-line application for performing network diagnostics and basic network security operations.

Features

- DNS Lookup
- Reverse DNS Lookup
- TCP Service Name Lookup
- TCP Port-to-Service Lookup
- TCP Port Scanning
- Local Host Information
- Network Host Scanning
- Network Interface Listing
- Routing Table Lookup
- Network Packet Sniffing
- ARP Scanning

Technologies

- Python 3
- Socket Programming
- Scapy
- ThreadPoolExecutor
- IP Address Handling

Requirements

Install Python 3 and Scapy.

pip install scapy

Run

From the root project directory:

python Console-Version/network_utility.py

Or navigate to this directory and run:

python network_utility.py

Security Notice

Use scanning and packet-capture features only on networks and systems you own or are explicitly authorized to test.

Some operations may require administrator or root privileges.
